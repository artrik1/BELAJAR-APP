Cara memakai CAK IMAM MINIMIZER PICTURE

Semua proses berjalan di browser Anda. Gambar tidak pernah dikirim ke server.

  1. Masukkan gambarSeret file ke kotak unggah, klik Pilih Gambar, Pilih Folder, atau tempel alamat URL lalu klik Ambil.
  2. Atur kualitasGeser slider (70% cocok untuk kebanyakan foto). Atau centang Mode otomatis cerdas agar kualitas dipilih sendiri.
  3. Pilih formatPilih JPG, WebP, AVIF, atau PNG. WebP biasanya paling hemat.
  4. Periksa hasilKlik Bandingkan lalu geser garis untuk melihat sebelum dan sesudah. Ubah pengaturan kapan saja, semua gambar dikompres ulang otomatis.
  5. SimpanSatu foto diunduh langsung. Lebih dari satu foto disimpan dalam 1 file ZIP lewat tombol Simpan sebagai ZIP. Tombol Bagikan muncul di HP yang mendukung.
  6. LaporanEkspor CSV berisi ukuran asli, ukuran hasil, dan persentase hemat. Gunakan kolom cari dan urutkan untuk banyak file.

Tips format

FormatCocok untuk
JPGFoto. Kompatibel di mana saja.
WebPWeb. Lebih kecil dari JPG, mendukung transparansi.
AVIFPaling kecil, tetapi tidak semua browser bisa membuatnya. Jika tidak didukung, hasil disimpan sebagai PNG.
PNGLogo dan screenshot. Ukuran dikecilkan lewat pengurangan warna (semakin rendah kualitas, semakin sedikit warna).
GIF / SVGDiubah menjadi gambar diam. Animasi GIF tidak dipertahankan.

Bagus untuk diketahui

Metadata EXIF (lokasi, kamera) dihapus secara default demi privasi. Aktifkan Pertahankan metadata EXIF jika perlu (hanya JPG ke JPG). Jika hasil lebih besar dari aslinya, gambar sudah terkompresi baik; turunkan kualitas. Ambil dari URL bisa gagal jika situs sumber memblokir akses (CORS); unduh gambarnya lalu unggah manual.
